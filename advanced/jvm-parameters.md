# JVM 参数

UPU 支持一些能够影响插件运行时行为的 JVM 参数，这些参数将会指定 JVM 运行时的系统属性。高级用户可使用这些参数以定义插件应以何种方式运行。与使用 `config.json` 配置文件的默认方式对比，命令行参数可用于核心初始化（如 `upu.locale`）。

## 用法

用法通常在所有 Java 可用的平台上一致。例如，如果你使用 `.bat` 或 `.sh` 文件启动服务器，你可以将系统属性添加到文件中，否则，就直接把它们加到启动命令里。例如：

```shell
java -Dupu.locale=zh-Hans -jar 服务端程序.jar
```

其中 `-D` 用于设置系统属性，系统属性 `upu.locale` 值为 `zh-Hans`。

## 参数

`-Dupu.locale=<locale>`——将以值为 `<locale>` 的语言用于 UPU 的显示语言。此参数会忽略配置文件定义的语言和系统默认语言，直接使用此参数定义的语言。由于配置加载处于插件加载阶段，因此在配置加载前的文本可能由您的系统语言或默认语言展示，设置此参数可以让这些文本也由您的语言展示。
